Problem Statement:
    Given an integer array arr of size n and an integer k, return the k most frequent elements. If there is a tie in frequency, return the smaller element first.

Input Format:
    First line: two integers n and k
    Second line: n space-separated integers representing the array

Output Format:
    A single line containing k space-separated integers (the top-k most frequent elements)

Constraints:
    1 ≤ n ≤ 10^5
    1 ≤ k ≤ n
    1 ≤ arr[i] ≤ 10^5
    All elements in the array are distinct in value (duplicates allowed)


Example 1:
    Input:
        10 2
        1 2 1 3 4 1 2 5 5 5

    Output:
        1 5

    Explanation:
        Frequency: 1→3, 2→2, 3→1, 4→1, 5→3
        Top-2 by frequency: 1 (freq 3) and 5 (freq 3)

Example 2:
    Input:
        8 3
        4 4 4 2 2 1 1 1

    Output:
        1 2 4

    Explanation:
        Frequency: 4→3, 2→2, 1→3
        Top-3: 1 (freq 3), 4 (freq 3), 2 (freq 2)
        Tie between 1 and 4 → smaller element 1 comes first

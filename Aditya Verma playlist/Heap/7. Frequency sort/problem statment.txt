Problem Statement:
    Given an integer array arr of size n, return a new array where elements are sorted by decreasing frequency. If two elements have the same frequency, the smaller value comes first. Each element appears in the result as many times as its frequency in the input.

Input Format:
    A single line of n space-separated integers

Output Format:
    A single line of n space-separated integers (the frequency-sorted array)

Constraints:
    1 ≤ n ≤ 10^5
    1 ≤ arr[i] ≤ 10^5

Example 1:
    Input: 1 2 1 3 4 1 2 5 5 5
    Output: 1 1 1 5 5 5 2 2 3 4
